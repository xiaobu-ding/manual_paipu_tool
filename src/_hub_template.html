麻将牌谱工具箱 · json6 生成

三个工具集成到一个网页：① 手输牌谱转 json6 · ② 当前牌局生成器 · ③ 雀魂牌谱抓取。生成的 json6 可直接交给 mortal / akochan 跑分，或粘到 tenhou.net/5 预览。

雀魂牌谱 → json6（浏览器扩展 / 用户脚本）

这是 Tampermonkey / Violentmonkey 用户脚本，需在 雀魂网页 内运行（它 hook 页面 WebSocket 抓牌谱回放），无法在本网页里直接抓。安装后打开任意 4 人牌谱回放，等加载完按 S 即自动下载 json6 并复制 tenhou.net/5 预览链接。

安装步骤
  1. 浏览器安装 Tampermonkey 或 Violentmonkey 插件。
  2. 点上方「复制用户脚本代码」→ 插件里「新建脚本」→ 粘贴 → 保存。
  3. 或点「下载 .user.js」→ 把文件拖进插件管理页完成安装。
  4. 打开雀魂 4 人牌谱回放，按 S 即可。

粘贴已导出的 json6 预览 / 校验

把雀魂脚本导出的 .json 内容（或任意 tenhou json6）粘到这里，点「格式化预览」查看结构并生成 tenhou.net/5 链接。
