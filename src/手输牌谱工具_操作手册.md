# 手输牌谱 → json6 转换工具 · 操作手册

## 一、这是什么
一个**离线单文件**网页工具（`manual_paipu_tool.html`），用来把一局麻将牌谱**手动录入**成 tenhou 的 **json6**（`.json`）格式，可直接交给 **mortal / akochan** 跑分；同时可生成 **tenhou.net/5** 预览链接，先看 replay 再跑分。

- 无需联网，双击 HTML 即可用浏览器打开。
- 不依赖任何外部库 / CDN。

## 二、打开方式
直接用浏览器（Chrome / Edge / Firefox 等）打开 `manual_paipu_tool.html` 即可。
工具内已内置一份「操作手册 / 记法说明」面板，可随时在页面底部展开查看。

## 三、牌张记法（雀魂 / 天凤通用）
一条手牌用「数字串 + 一个花色字母」表示，同花色可连写。

| 种类 | 后缀 | 写法 | tenhou 数字 |
|------|------|------|-------------|
| 万子 | m | `1m 2m … 9m` | 11–19 |
| 筒子 | p | `1p 2p … 9p` | 21–29 |
| 索子 | s | `1s 2s … 9s` | 31–39 |
| 字牌 | z | `1z`东 `2z`南 `3z`西 `4z`北 `5z`白 `6z`发 `7z`中 | 41–47 |
| 赤5（红宝牌） | 0 | `0m` `0p` `0s` | 51 / 52 / 53 |

示例：
- `123456789m12345p` = 123456789万 + 12345筒（共 14 张）。
- `111m` = 三张 1 万；`0m` = 赤 5 万（tenhou 记 51）。

## 四、摸打与鸣牌记法（工具会自动生成，不必手敲）
| 动作 | tenhou 记法 | 含义 |
|------|-------------|------|
| 打牌 | 数字（如 `35`） | 普通切牌 |
| 立直宣言打 | 前缀 `r`（如 `r35`） | 立直的那一张 |
| 摸切 | `60` | 刚摸的牌直接打出 |
| 吃 | `c` + 被吃 + 自己2张（如 `c232425`） | 来自上/对/下家 |
| 碰 | `p` + 被碰 + 自己2张（如 `p212121` 1筒碰） | |
| 大明杠 | `m` + 被杠 + 自己3张 | |
| 暗杠 | `a` 收尾（如 `323232a32` 2索暗杠） | |
| 加杠 | `k` 收尾（如 `k313131`） | 碰后加一张 |

在本工具里，你只需选「动作类型 + 填牌（可点牌面按钮）+ 选来自谁（上/对/下家）」，程序会替你拼出上述前缀串。

## 五、分步操作
1. **① 对局信息**：填标题、规则（南喰/东喰）、赤牌有无、四家昵称、起始点数（可选，逗号分隔 4 家）。
2. **② 牌张输入面板**：先点某个输入框使其高亮（边框变蓝），再点牌面按钮即可「打」牌进去；也可直接手打记法。
   - 颜色：万(m)蓝、筒(p)绿、索(s)橙、字(z)紫；红底=赤5。
3. **③ 添加一局**：
   - 选 东1…南4、本场数、立直棒数、宝牌指示牌、里宝牌（和了时填）。
   - 每家填**配牌**（庄家 14 张、闲家 13 张）。
   - 用「动作」逐条录入：`摸+打` / `碰` / `吃` / `大明杠` / `暗杠` / `加杠`（可勾「立直」「摸切」）。
4. **本局结果**：选 自摸 / 荣和 / 流局 / 流し満貫 / 途中流局，填赢家、放铳家、**Δ点数（4家，逗号分隔，建议照抄雀魂结算画面）**、符番点数说明与役（每行一个，如 `立直(1飜)`）。
5. **④ 导出**：点「下载 json6」保存 `.json`（交给 mortal/akochan）；或「复制 tenhou.net/5 链接」先看 replay。右侧实时显示完整 json。

## 六、与 tenhou.net/6 的对照 & 提示
- tenhou.net/6 自带「手動入力」，但记法较硬核；本工具用按钮+表单降低门槛，导出格式与 tenhou.net/5/6 完全兼容。
- **庄家配牌填 14 张**（含首摸那张），闲家 13 张；首摸之后每次「摸+打」都作为一条动作录入。
- **Δ点数（各家增减）**建议直接从雀魂结算画面照抄，避免手算出错：自摸时赢家 Δ 为正、其余为负。
- **三麻（3 人）暂不支持**（mortal 跑分为 4 人）；途中流局填役名如 `九種九牌` / `四風連打` / `四家立直` / `四開槓`。
- 导出后的 `.json` 交给 mortal / akochan 即可跑分。

## 七、常见问题
- **预览链接打不开？** tenhou.net 对单文件体积有限制；整场多局请下载 `.json` 用 mortal/akochan 打开，预览链接建议用「单局」。
- **赤5 怎么填？** 用 `0m` / `0p` / `0s`。
- **鸣牌「来自谁」怎么选？** 从被鸣者的视角：你（自家）的上家 / 对家 / 下家。
- **立直/摸切没生效？** 在「摸+打」动作里勾对应复选框；立直只作用于该次打牌，且通常是该玩家最后一次摸切前的那张。
